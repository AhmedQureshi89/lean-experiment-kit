# 🧪 Method list

The experiment methods are the 44 named in **_Testing Business Ideas_** by David J. Bland and
Alexander Osterwalder (Wiley, 2019), also published as the Strategyzer experiment library. This file
lists their **names and numbers only**, so that every test card names its method the same way and
`dashboard/build_data.py` can check the name. What each method is, when to use it, what it costs and
how far to trust it are in the book. Get the book: this kit is a way to keep a record while you
follow it, not a substitute for it.

This kit is not affiliated with or endorsed by the authors, Wiley or Strategyzer.

**Naming rule:** write the method in a card header as `#NN Name`, exactly as below
(e.g. `#35 Simple Landing Page`). If your test is none of the 44, write
`Custom (closest: #NN Name)` with the nearest one.
